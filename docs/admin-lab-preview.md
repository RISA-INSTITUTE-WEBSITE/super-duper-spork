# Administrator-only lab preview

Labs are temporarily unreleased. Sign in as a verified administrator and open
Administration Centre → Labs — private preview (/admin/labs). All existing
computing, physics, cloud and DevOps, security and practical workspace
components remain intact, including the Python runtime and library manager.

Each lab page checks current administrator membership on the server before
rendering. The previous /labs entry redirects administrators to the private hub;
the existing direct lab URLs and Python sandbox route also require an admin
session. Learner-facing navigation, search and topic links are removed.
The practical submission page and its server action are admin-only during this
preview. Existing enrolments, submissions, lecturer assignments and curriculum
lab mappings are preserved; no data or database policies are deleted or changed.
The learner-facing pages use the existing role registry, not an editable
profile field. Restore learner navigation and access only after an explicit
release decision. Previously downloaded browser code cannot be recalled.
