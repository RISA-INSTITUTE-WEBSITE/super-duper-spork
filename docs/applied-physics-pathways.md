# Applied Physics pathways

The public curriculum preview mirrors the 27 November 2026
[RISA Curricular proposal](https://github.com/RISA-INSTITUTE-WEBSITE/Curricular/blob/0add0b03e4c770d2d691baee1b93e06220819c38/curricula/physics/pathways.md).
The module register is taken from its physics README.

- `/programmes/physics/pathways` lists AP01–AP12.
- Each pathway has a detail route with the shared 21-module register, teaching
  order, module-specific package recommendations and research direction.
- Only existing published module records receive preview links. Draft or missing
  modules are not created or published by this feature.
- PHY304 remains optional. AP codes are pathway identifiers, never module codes.
- Existing authentication, enrolment, lesson progress and lab access are unchanged.

The preview is not a qualification, professional registration or a pathway
enrolment mechanism. Academic review, credit validation, module content and
persistent pathway selection remain separate work. When the Curricular source
changes, update the mirrored data and tests in the same PR.
