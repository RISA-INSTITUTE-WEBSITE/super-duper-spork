# RISA Virtual Laboratories

The Labs link opens the public hub at `/labs`. The original Computing Lab
remains at `/computing-lab` with its binary and logic checkpoints.

| Domain | Module | Interactive activity |
| --- | --- | --- |
| Computing | CS101 | Binary and logic gates |
| Physics | PHY101 | Constant acceleration and Newton's second law |
| Cloud & DevOps | DVE201 | Simulated build, test and deploy |
| Ethical Hacking | COMS101 | Fictional least privilege access decisions |

All new activities run entirely in the browser. No user code is executed,
no external infrastructure is contacted, and no real account permissions
are changed. Practice is public and session-based, not a formal assessment.
Existing protected course access and enrolment policies remain unchanged.

Unit tests verify equations, pipeline gating and permission decisions.
Browser tests verify navigation, controls, feedback and invalid routes.
Further work includes additional module-specific simulations and authenticated
practice progress.
